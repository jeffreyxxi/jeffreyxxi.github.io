# AI 文档 Skill

按 `docs/ai/` 的结构生成或补充 AI 相关技术文档。

## 目录职责

- `docs/ai/readme.md`：AI 学习与实践总览页
- `docs/ai/agent-tools.md`：Agent 工具链、产品定位、能力边界、适用场景
- `docs/ai/model-selection.md`：模型搭配、主力组合、阶段性选型结论
- `docs/ai/practice-plan.md`：真实实践计划、实施步骤、问题复盘、操作记录
- `docs/ai/references.md`：官方资料入口

如果现有文件仍不够，应优先在 `docs/ai/` 下继续拆分，而不是把不相关内容重新堆回单一文档。

## 目标读者

- 个人复盘与梳理
- 关注 AI Agent、大模型的最新知识，探索Agent和大模型的搭配使用，以创造实际价值为目的。

## 文档结构建议

1. **总览页**
   - 说明目录用途
   - 给出各篇文档入口
   - 记录当前阶段判断
2. **工具链页**
   - Agent 工具分类
   - 主流产品定位
   - 能力边界与适用场景
3. **模型选型页**
   - 主力模型
   - 模型搭配
   - 个人阶段性选型结论
4. **实践计划页**
   - 计划目标
   - 分阶段实施步骤
   - 问题复盘和记录模板
5. **资料入口页**
   - 官方文档
   - 长期核对入口

## 写作规则

- 使用中文编写内容
- 结构清晰，先总览后细分
- 采用 Markdown 格式，并保持 VuePress frontmatter
- AI 内容默认写入 `docs/ai/`，不要再默认写入 `docs/tools/`
- 优先按主题拆文档，不要把工具综述、模型选型、实践记录混成一篇
- 当用户已有明确实践计划时，实践型内容优先写入 `docs/ai/practice-plan.md`
- 实践型内容优先写成“目标 -> 分阶段步骤 -> 操作记录模板 -> 问题复盘模板”的结构
- **所有信息必须准确，不能提供错误信息或虚假杜撰信息**
- **所有信息的时间必须以当下搜索或每次更新文档的时间节点为准，不能提供过去太久的无意义信息**
- **文档支持长期更新，用户会要求 AI 工具联网搜索最新信息，并整理到 `docs/ai/` 目录中**
- 当用户在执行过程中反馈报错、现象、修复方案时，应优先沉淀到 `docs/ai/practice-plan.md`

## 输出位置

- 首选写入 `docs/ai/` 对应文件
- 若是总览，更新 `docs/ai/readme.md`
- 若是工具链综述，更新 `docs/ai/agent-tools.md`
- 若是模型与组合，更新 `docs/ai/model-selection.md`
- 若是实践步骤、部署过程、报错与修复，更新 `docs/ai/practice-plan.md`
- 若是资料索引，更新 `docs/ai/references.md`

## 使用场景

- 当用户需要整理 AI 工具链、主流模型、使用思路时使用
- 当用户需要记录探索 AI 产生成果时，记录到 `docs/ai/` 对应文档
- 当用户需要把某个 AI 自动化计划、Agent 部署过程、问题排查过程整理成长期文档时，也使用本 Skill
