### 设计原则

1. **单文件不过长**：错题按日期拆分（`errors/`），避免百万 token 级文件
2. **数据与结论分离**：`progress.md` 存量化数据，`memory.md` 存质性诊断
3. **所有图片统一管理**：`images/` 集中存放，md 文件中用相对路径引用
4. **目录即导航**：每个模块一个 md 文件，VuePress 自动生成侧边栏

## 3. 核心文件职责详解

### 3.1 `plan.md` — 百日总计划

**性质**：静态参考文件，基本不修改。定义阶段划分、模块分配、里程碑节点。

**内容**：
- 四阶段框架（阶段目标、天数、总时长）
- 阶段一 35 天模块分配表
- 里程碑节点（如「Day 35 完成系统筑基」「Day 60 完成专项突破」）

**更新人**：Hermes（仅在计划变更时修改）

---

### 3.2 `progress.md` — 进度仪表盘

**性质**：动态文件，每次练习后 Hermes 追加更新。单文件，但保持紧凑。

**内容**：
- 模块进度总览表（状态、完成度、正确率、薄弱等级、最后练习时间）
- 每日学习日志（日期、模块、时长、完成内容、正确率、错题编号范围）

**更新人**：Hermes（每次批改后自动更新）

**格式示例**：
```markdown
## 模块进度总览

| 模块 | 状态 | 完成度 | 正确率 | 薄弱等级 | 最后练习 |
|------|------|--------|--------|----------|----------|
| 判断推理 | 进行中 | 3/7天 | 72% | ⚠️ 中 | 06-02 |
| 言语理解 | 未开始 | 0/6天 | — | — | — |

## 学习日志

### 2026-06-02 | 判断推理 Day 3 | 4h
- 完成：逻辑判断-假言命题（理论 + 15题）
- 正确率：11/15 = 73%
- 错题编号：#E0031~#E0034
- 备注：充分必要条件混淆仍是主要问题
```

---

### 3.3 `memory.md` — 备考记忆

**性质**：质性诊断文件。与系统 Memory 互补——系统 Memory 记环境和配置，本文件专记备考学习画像。

**内容**：
- 学习画像（擅长/不擅长的类型、学习风格偏好）
- 知识薄弱画像（按模块细分具体薄弱点）
- 策略调整记录（何时、为什么调整了学习策略）
- 备考偏好（出题偏好、解析偏好、时间偏好等）

**更新人**：Hermes（阶段性总结时更新，非每次练习）
**更新原则**：只写诊断结论，不写流水账。每次更新追加日期戳。

---

### 3.4 `errors/` — 错题本

**性质**：按日期拆分的错题记录，一个文件对应一天的练习。结构化字段便于 Hermes 检索分析。

**内容（每道错题）**：
```markdown
### #E0031 | Δ假言命题 | ⚠️错 | 2026-06-02

**题干**：[题目文本，如有配图用 ![](../images/xxx.png)]

**你的答案**：A（天不下雨）
**正确答案**：B（无法确定）
**错误类型**：概念混淆
**解析**：逆否命题的适用条件……
**关联知识点**：充分条件假言命题 → 逆否推理
**重做次数**：0
```

**字段说明**：

| 字段 | 说明 |
|------|------|
| 编号 | `#E` + 四位数字，全局唯一递增 |
| 标签 | 知识点关键词（如 `Δ假言命题`），用于快速分类 |
| 状态 | ⚠️错 / ❌重错 / ✅已掌握 |
| 错误类型 | 概念混淆 / 计算失误 / 审题不清 / 知识盲区 / 方法错误 |
| 关联知识点 | 层级化的知识点路径，方便追溯学习 |
| 重做次数 | 追踪该错题被重做了几次 |

---

### 3.5 `images/` — 题目配图

**生成方式**：

| 题型 | 图片类型 | 工具 |
|------|----------|------|
| 资料分析 | 折线图、柱状图、饼图、表格 | Python matplotlib |
| 图形推理 | 几何图形、空间旋转、立体展开 | Python matplotlib / PIL |
| 实验设计 | 流程图、装置示意图 | Python matplotlib |
| 科技文献 | 数据结构图、对比图 | Python matplotlib / SVG |

**引用方式**：md 文件中 `![](../images/xxx.png)`，VuePress 构建时作为静态资源处理。

**飞书推送**：Hermes 使用 `MEDIA:路径` 直接发送图片附件。

## 4. 交互工作流

### 4.1 日常练习流程

```
┌─────────────────────────────────────────────────────────┐
│                     每日飞书交互                          │
├─────────────────────────────────────────────────────────┤
│  Hermes 出题（含配图）                                   │
│     │                                                    │
│     ├── 读取 memory.md → 获取薄弱画像                     │
│     ├── 读取 progress.md → 获取当前进度                  │
│     ├── 读取 errors/最近几天 → 获取错题分布              │
│     └── 读取 plan.md → 确认今日学习内容                  │
│     ↓                                                    │
│  用户做题（飞书回复答案）                                 │
│     ↓                                                    │
│  Hermes 批改                                             │
│     │                                                    │
│     ├── 飞书回复：批改结果 + 解析                        │
│     ├── progress.md：追加今日日志 + 更新总览表            │
│     ├── errors/YYYY-MM-DD.md：追加错题（结构化）           │
│     └── memory.md：如达阶段节点，提炼诊断结论              │
└─────────────────────────────────────────────────────────┘
```

### 4.2 阶段模考流程

1. Hermes 收集真题/生成模拟卷 → 写入 Markdown
2. VuePress 构建 → HTML 页面
3. Puppeteer 脚本 → 导出 PDF
4. 用户打印、限时做题
5. 飞书回传答案 → Hermes 批改
6. 更新 `progress.md`、`errors/`、`memory.md`

### 4.3 新会话恢复

Hermes 每次出题前读取以下文件恢复上下文：
1. `progress.md` → 进度状态
2. `memory.md` → 学习画像
3. `plan.md` → 阶段目标

## 5. 题源策略

### 5.1 方案：混合路线

| 题源 | 用途 | 获取方式 |
|------|------|----------|
| 网络真题 | 确定题型结构、阶段模考 | `web_search` 搜公开题库 |
| AI 生成 | 日常练习、错题同类变体 | DeepSeek 根据知识点生成 |
| 大纲例题 | 了解官方出题风格 | 从考试大纲文档中提取 |

### 5.2 质量把控

- 初期搜到的真题需要用户人工审核质量
- AI 生成的题目需标注 `[AI]`，与被认定的真题区分
- 几次审核后 Hermes 对标合格的题目建立质量标准

### 5.3 同类题生成策略

当某道题做错时，Hermes 自动生成 1-2 道**同类变形题**（相同知识点、不同数据/题干），用于巩固。而非重复原题。

## 7. 百日计划框架

### 7.1 四阶段总览

| 阶段 | 天数 | 时长 | 目标 |
|------|------|------|------|
| 一：系统筑基 | Day 1-35 | ~140h | 地毯式过知识点，建立完整知识体系 |
| 二：专项突破 | Day 36-60 | ~100h | 弱项攻坚 + 综应强化 |
| 三：真题实战 | Day 61-80 | ~80h | 限时模考 + 系统复盘 |
| 四：冲刺收网 | Day 81-100 | ~80h+ | 全真模拟 + 查漏补缺 |

### 7.2 阶段一模块分配（35 天）

| 模块 | 天数 | 理由 |
|------|------|------|
| 判断推理 | 7 | 题量最大（~35题），含 4 个子模块 |
| 言语理解 | 6 | 需要积累语感和阅读速度 |
| 数量关系 | 5 | 公式体系需要重新建立 |
| 资料分析 | 4 | 技巧性强，重在速算方法 |
| 常识判断 | 5 | 重点攻克科技常识 |
| 实验设计 | 3 | C 类独有模块，可借助理工背景优势 |
| 综合应用能力基础 | 5 | 四个题型入门 + 作文框架搭建 |
