## 备考偏好

> 出题偏好、解析偏好、学习时间偏好等

- 交互方式：飞书双向（出题 → 用户回复 → 批改解析）
- 学习风格：先讲知识点再刷题，不接受盲测
- 解析偏好：越详细越好，不介意长回复
- 错题巩固：需要同类变形题，不要重复原题
