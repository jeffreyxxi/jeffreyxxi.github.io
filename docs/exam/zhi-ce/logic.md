## Day 1：图形推理 — 位置类

> 🎯 目标：掌握平移、旋转、翻转三种位置变化规律

### 一、什么是位置类图形推理

**识别标志**：图形中的元素组成**基本相同**（形状不变），但**位置发生变化**。

> 核心思路：元素没变，变的是它在哪、朝哪。

### 二、三大规律

#### 1. 平移（Translation）

元素沿某个方向移动到新位置。

- **方向**：上/下/左/右、对角线、顺时针/逆时针
- **步数**：恒定（每步移 1 格）或递增（1→2→3 格）
- **路径**：直线、折线、循环（到头后折返）

> 📌 做题技巧：先看第一个到第二个怎么变的，再看第二个到第三个，找规律。

#### 2. 旋转（Rotation）

元素绕某一点转动一定角度。

- **方向**：顺时针 / 逆时针
- **角度**：常见 45°、60°、90°、120°、180°
- **特殊**：可能整体旋转，也可能局部旋转

> 📌 做题技巧：找一个最明显的元素（如箭头、三角形），追踪它的方向变化。

#### 3. 翻转（Flip / Mirror）

元素沿某条轴线镜像。

- **水平翻转**：左右互换（沿竖轴）
- **垂直翻转**：上下互换（沿横轴）

> 📌 做题技巧：翻转后的图形与原图「镜像对称」；旋转 180° ≠ 水平翻转，注意区分。

### 三、组合考查

实际考试中往往**多种规律叠加**，比如：
- 先平移再旋转
- 不同元素执行不同操作（分层规律）

### 练习 6 | 分层规律

```
外层：    □ → ○ → △ → ？
内层：    ● → ○ → ● → ？
（外层和内层各自独立变化）
```

外层规律：□ → ○ → △（每次换一种形状）
内层规律：● → ○ → ●（黑白交替）

**问题**："？"处外层和内层各应该是什么？

A. 外层 □，内层 ○
B. 外层 □，内层 ●  
C. 外层 ○，内层 ○
D. 外层 △，内层 ○

---

## 答案（仅供 Hermes 批改使用，请勿直接查看）

1. A — 平移规律：每次向右移 1 格，所以第 4 步在第 4 列
2. B — 旋转规律：每次顺时针转 45°，↑→↗→→→↘
3. C — 水平翻转：倒三角左右镜像后形状不变（等腰三角形水平翻转后仍是倒三角）
4. B — 平移规律：4 个位置循环，●走到最右侧（第 4 位）
5. A — 旋转规律：每次顺时针 90°，尖朝下再转 90° = 尖朝左
6. A — 外层形状循环 □→○→△→□（回到第一个），内层黑白交替 ●→○→●→○
