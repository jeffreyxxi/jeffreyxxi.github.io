# AI 学习与实践

## 说明

- 信息更新时间：`2026-04-29`
- 本目录用于集中维护 AI 相关文档，不再和普通工具文档混放
- 本目录既记录 AI 工具链与模型选型，也记录我自己的真实实践过程
- 本目录默认优先服务于“前端工程师向全栈过渡、尝试独立完成小项目全生命周期”的学习目标

## 目录导航

- [AI Agent 工具链](/ai/agent-tools)

## 这个目录主要解决什么问题

- 我该优先关注哪些 AI Agent 工具
- 不同模型适合做什么，应该怎么搭配
- 如何把 AI 从“聊天工具”变成“真实生产力工具”
- 如何把自己的实践过程、报错、排查和结论沉淀成长期资产

## 文档分工

### `agent-tools`

用于记录 Agent 工具地图、产品定位、能力边界、适用场景。

### `model-selection`

用于记录模型搭配、主力组合、长期选型结论，以及和个人成长路径的关系。

### `practice-plan`

用于记录真实计划、实施步骤、问题复盘、操作模板和阶段结论。

### `references`

用于集中维护官方资料入口，方便后续继续核对与更新。

## 当前阶段判断

- 主力编码 Agent 仍优先关注 `Codex + GPT-5.4`
- IDE 内高频协作继续关注 `Cursor`、`GitHub Copilot`、`Windsurf`
- 如果目标是学会 Agent，而不只是会用某个产品，必须持续补开放栈
- 如果目标是让 AI 真正帮我做事，就要把注意力放到消息入口、任务编排、自动化和发布链路上

## 后续维护方式

- 工具与模型综述，优先更新到对应专题页
- 真实部署、报错、修复过程，优先更新到 [AI 自动化实践计划](/ai/practice-plan)
- 当新的稳定经验会长期影响协作方式时，再同步更新 `AGENTS.md` 或 `ai-skill/SKILL.md`
