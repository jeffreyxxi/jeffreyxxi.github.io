# 股票笔记 Skill

按 `docs/notes/stock.md` 的格式生成或补充股票相关学习笔记。

## 笔记结构

1. **Frontmatter**（YAML，必须）

   - `prev`: 上一篇笔记，含 `text`、`link`；无则省略或留空。
   - `next`: 下一篇笔记，含 `text`、`link`；没有下一篇则设为 `false`。

2. **标题层级**

   - 一级：`# 股票技术分析指标学习笔记`（或当前主题标题）
   - 二级：`## 基础知识`、`## 交易笔记`、`## 技术指标` 等大模块
   - 三级：`### 交易原理`、`### 现价和五档盘口` 等具体概念；交易笔记下每条记录用 `### 日期 简短描述`（如 `### 2025-02-03 某标的建仓`）

3. **交易笔记模块**（位于「基础知识」之后）

   - 每条交易笔记必须包含以下五项，顺序固定：
     - **日期**：交易发生日期（建议格式 YYYY-MM-DD）。
     - **交易**：标的（代码/名称）、买卖方向、数量、价格或价格区间。
     - **背景情况**：当时大盘、板块或个股的简要情况（如指数位置、消息面、技术形态等）。
     - **交易原因或当时想法**：为何下单、当时的判断与依据。
     - **复盘**：事后总结，包括对错、可改进点、经验教训。
   - 同一篇笔记内可有多条交易记录，每条用三级标题 + 上述五项列表。

4. **正文**

   - 以短句 + 列表为主，每条概念单独成点。
   - 子规则用二级列表，例如：`价格优先 > 时间优先` 下再列「价格优先」「时间优先」的说明。
   - 公式单独一行，乘号用反斜杠转义：`总市值 = 股价 \* 总股本`。

5. **重要提示**

   - 用引用块 `> **_<span style="color:#409EFF" >...</span>_**` 表示补充说明（蓝色）、概念延申等。
   - 用 `> **_<span style="color:#67C23A" >...</span>_**` 表示风险/利空等警示（绿色）。
   - 用 `> **_<span style="color:#F56C6C" >...</span>_**` 表示机会/利好等机会提醒（红色）。
   - 引用块前后各空一行，与列表区分开。

6. **语言与风格**
   - 中文，表述简洁，适合复习和查阅。
   - 不要使用富文本、表情、emoji 等花里胡哨的内容。

## 模板

```markdown
---
prev:
  text: 上一篇标题
  link: /path/to/prev
next: false
---

# 股票技术分析指标学习笔记

## 基础知识

### [概念名]

- 定义或原理（一句话）。
- 规则或要点：
  - 子要点 1。
  - 子要点 2。

### [另一概念]

- 说明。
- 公式：某量 = 甲 \* 乙

  > **_<span style="color:#409EFF" >补充说明（蓝色）</span>_**

  > **_<span style="color:#67C23A" >风险或警示（绿色）</span>_**
```

## 交易笔记模板

每条记录必须包含：**日期**、**交易**、**背景情况**、**交易原因或当时想法**、**复盘**。格式如下：

```markdown
## 交易笔记

### 2025-02-03 某标的建仓

- **日期**：2025-02-03
- **交易**：标的 XXX（代码），买入，数量 N 手，价格/区间 X.XX 元
- **背景情况**：当时大盘/板块/个股简要情况（如指数位置、消息、技术形态等）
- **交易原因或当时想法**：为何下单、当时判断与依据
- **复盘**：事后总结、对错、可改进点或经验教训

### 2025-02-05 某标的减仓

- **日期**：2025-02-05
- **交易**：标的 XXX，卖出，数量 N 手，价格/区间 X.XX 元
- **背景情况**：……
- **交易原因或当时想法**：……
- **复盘**：……
```

- 同一篇笔记内可有多条记录，每条用三级标题（日期 + 简短描述），下跟上述五项列表。
- 复盘部分可酌情使用引用块做警示或补充（颜色规范同「重要提示」）。

## 输出位置

- 新建笔记：写入 `docs/notes/` 下，文件名与主题相关（如 `stock.md` 或新开 `kline.md` 等）。
- 补充现有笔记：在 `docs/notes/stock.md` 中按上述格式追加小节，并保持全文层级与风格一致。
